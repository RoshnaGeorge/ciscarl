# Historical records (not canonical)

These files were produced on the earlier **treatment-only split** of ACTG175
(overall tau +0.143, rule `cd40 <= 343.5 & age > 28.5 & homo <= 0.5`).

The canonical analysis uses the A×E split (overall tau +0.124, rule
`cd40 <= 407.5 & wtkg > 71.0 & homo <= 0.5`) and is reported in
`results/CANONICAL_RESULTS.md`, `results/CLAIMS_v1.17.md` and
`results/EVIDENCE_EXTENSION.md`.

They are kept only because `FINAL_AUDIT.md` cites them as the historical audit
trail. Do not use their numbers.

| File | What it is |
|---|---|
| `actg175_c200.md` | Console record of the pre-canonical C200 run |
| `actg175_leaf_table.csv` | Candidate leaves under the old split |
| `actg175_km_check.csv` | Kaplan-Meier check under the old split |

The canonical equivalents are `actg175_leaf_table_v2.csv` and
`actg175_marginal_v2.csv`.
