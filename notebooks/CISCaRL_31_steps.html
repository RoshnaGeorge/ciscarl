CISCaRL — the complete pipeline in 31 steps¶

One project, one dataset, one baseline. Every step has three parts: a box saying what we do and which concepts are used, the code that runs it, and a box saying what the output means and why it forces the next decision.

Estimand: $\tau(730\mid x)=S_1(730\mid x)-S_0(730\mid x)$, composite progression-free endpoint. Roles: discovery / validation / assessment, disjoint. Baseline: SCRE on identical splits.

How to run.

  • RUN_HEAVY = False (default): every cell loads the recorded evidence and the notebook executes in under two minutes.
  • RUN_HEAVY = True: the post-freeze gates can be re-run from their modules; Gates 31–33 can take 2–3 hours. The exact command is printed in each step.

Execution order is not cosmetic. The split happens before any fitted transform, the operating point is chosen on validation, and the assessment partition is read once at the end.

PCA and wavelets solve a different problem. PCA would turn the 12 clinical variables into artificial components, and the tree would then produce rules such as "principal component 1 ≤ 0.45" — uninterpretable clinically. Wavelets extract time–frequency structure from signals, which these static baseline covariates are not. Since interpretability is the point of CISCaRL, the original clinical variables are retained and reduced by justification, not by projection.

On the real trial the validation standard error is best at 60/20/20 (0.126) but commitment collapses to 5 %: the larger discovery set selects a leaf that clears the 200-patient floor (support 208), and larger leaves carry smaller effects, so the lower bound is the most negative (−0.110). The 20/20 rule instability is a stronger statement about the model than the ratio comparison itself, and it is consistent with the Jaccard ≈ 0.34 measured in the stability study.

Policy value and net benefit¶
Concepts. Treatment policy · policy value · net benefit · decision curve ·
cost–benefit trade-off.


A rule is a policy. Its value is the expected 730-day event-free survival if that
policy assigns treatment:


$$V(d)=E\left[S_{d(X)}(730\mid X)\right]$$


Net benefit subtracts the burden of treating: $U(d)=V(d)-\lambda\cdot\text{treat rate}$,
where $\lambda$ is the cost of one treated patient in the same units as the
survival probability. Reported below for 40 paired replications per design.

    return float(KaplanMeierFitter().fit(t, e, timeline=[x]).survival_function_.iloc[0, 0])


def km_diff(days, events, arm, seed=0, B=500):
    t1, e1 = days[arm == 1], events[arm == 1]
    t0, e0 = days[arm == 0], events[arm == 0]
    d_obs = km_at(t1, e1) - km_at(t0, e0)
    rng = np.random.RandomState(seed)
    bs = []
    for _ in range(B):
        i1 = rng.randint(0, len(t1), len(t1))
        i0 = rng.randint(0, len(t0), len(t0))
        bs.append(km_at(t1[i1], e1[i1]) - km_at(t0[i0], e0[i0]))
    lo, hi = np.percentile(bs, [2.5, 97.5])
    return d_obs, float(lo), float(hi), len(t1), len(t0)
